# Задачи

**Задача 1**

Напишете функция, която приема две числа и връща сумата им. Принтирайте резултата.

Вход:
```
2 3
```

Изход:
```
5
```

**Задача 2**

Напишете функция, която не приема параметри и принтира на конзолата ```"Hello, world!"```.

**Задача 3**

Напишете функции ```isUppercase``` и ```isLowercase```, които приемат параметър символ и връщат съответно дали е главна или малка буква. Приемаме, че работим само с латински букви. Принтирайте резултата.

Вход (за isUppercase):
```
j
```

Изход:
```
false
```

Вход (за isLowercase):
```
l
```

Изход:
```
true
```

**Задача 4**

Напишете функция, която приема параметри две числа и операнд (тип ```char``` с възможни стойности ```-```, ```+```, ```*```, ```/```) да връща резултата от израза. Принтирайте резултата.

Вход:
```
4 5 *
```

Изход:
```
20
```

**Задача 5**

Вход:

```

Изход:

```

**Задача 10**

Напишете програма, която приема цели числа `x` и `a`, `b`, `c`, `d`, `e`, `f` (граници на затворени интервали - `[a, b]`, `[c, d]`, `[e, f]`) и определя дали точката е в обединението на първите 2 и не е в третия. Принтирайте резултата. Валидирайте интервалите. Помислете каква част от логиката може да запишете във функция и да преизползвате по лесно.

Вход:
```
3 2 5 4 9 -15 2
```

Изход:
```
true
```
