# Задачи

**Задача 1:**
Напишете програма, която отпечатва в конзолата текста "Hello World!".  

Изход:
```
Hello World!
```

**Задача 2:**
Напишете програма, която чете от конзолата 2 цели числа - дължините на двете страни на правоъгълник. Да се принтира неговия периметър и лице в конзолата.

Вход:
```
4 3
```
Изход:
```
Perimeter: 14
Area: 12
```

А сега пробвайте и с дробни числа.

**Задача 3:**
Напишете програма, която да разменя стойността на две променливи, съдържащи цели числа.

``` c
int a = 5;
int b = 12;

//your code here

printf("%d %d", a, b);
```

Изход:
```
12 5
```
*Бонус: опитайте се да го направите без да ползвате трета променлива :)*

**Задача 4:**
Напишете програма, която прочита 3-цифрено число от конзолата и принтира сбора на 3-те цифри, от които е съставено.

Вход:
```
123
```
Изход:
```
6
```

**Задача 5**  

Напишете програма, която по подадени дължини на страните на триъгълник, определя дали е валиден триъгълник и отпечатва резултата на конзолата.

Вход:
```
1 3 9
```
Изход:
```
0
```
---

Вход:
```
3 4 5
```
Изход:
```
1
```


**Задача 6**  

Напишете програма, която по подадени координати на точка (x, y) и радиус r на окръжност проверява дали точката лежи в окръжността или не и отпечатва на конзолата резултата от проверката. Окръжността приемаме, че е с център (0, 0).

Вход: (x y r)
```
1 2 4 
```

Изход
```
1
```
---

Вход:
```
6 7 2
```

Изход
```
0
```
