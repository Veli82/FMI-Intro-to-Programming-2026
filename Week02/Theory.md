## Какво е програма?
Програмата е последователност от инструкции, които процесорът на компютъра изпълнява. Когато стартирате програмата, тези инструкции, заедно с допълнителни данни/стойности, които са нужни за изпълнението на инструкциите, се зареждат в **оперативната памет** (RAM). Там живее нашата програма когато работи (оперира :)).  
От тук нататък, когато казваме *памет*, ще имаме предвид *оперативната памет (RAM)*, да не се бърка с паметта на диска!! (там, където седят файловете - HDD, SSD)


## Процес на компилация
Компютърът не разбира кода, който ние пишем. Той работи с 0 и 1 или още наричан машинен език (machine language). Когато се създава един език за програмиране, заедно с него се създава много важна **програма**, чиято единствена задача е да преведе нашия код от езика за програмиране до езика на компютъра (0 и 1). Има два такива типа програми, които се различават фундаментално: компилатори и интерпретатори. Ние ще се занимаваме с първия тип, защото езикът C се компилира (както и C++, C# и други). При процесът на компилация, компилаторът чете целия ни код наведнъж и създава от него изпълним файл (executable), който представлява инструкциите и съпътстващите ги данни, преведени на машинен език.


## Какво е IDE?
**IDE (Integrated Development Environment)** е една мощна програма, която комбинира няколко основни инструмента, нужни на програмиста за да пише своя код бързо и ефективно. Обикновено включва **редактор на код**, **компилатор/интерпретатор**, **дебъгер** и често други полезни функционалности като автодопълване на кода, подчертаване на синтаксис, управление на проекти и интеграция с системи за контрол на версиите (например Git). Целта на IDE е да улесни процеса на писане, тестване и поддръжка на програмен код, като събира всички нужни инструменти на едно място и прави работата по-ефективна.

## Променливи
Докато програмата работи, инструкциите и данните за нашата програма седят на дадено място в паметта. Всяко място в паметта си има *адрес* (то е числена стойност). Когато ни трябва да ползваме памет, за наше улеснение може да сложим **име на нейния адрес** и ще ползваме това име, когато искаме да извлечем данните, запазени на този адрес. Това място в паметта с дадено име се нарича **променлива**. Тя се използва за съхраняване на данни/стойности в паметта, които могат да бъдат *променяни* по време на изпълнението на програмата. Езикът C е силно типизиран език и за всяка променлива трябва да посочим *какъв тип данни* ще се намират в нея.
Променливи се създават по следния начин:

``<тип> <име>;``\
``<тип> <име> = <стойност>;``

Пример:
```c
int height = 175;
double weight = 70.2;
unsigned age; // няма стойност
```

*Забележка: имената на променливи могат да започват само и единствено с буква или долна черта. След първият позволен символ, се допускат и цифри.*

Булева променлива (тип bool) представлява променлива, която съдържа една от две възможни стойности - `true` или `false`. В езика C няма такъв примитивен тип, за това ще използваме стойностите **1** (false) и **0** (false) в комбинация с някой целочислен тип.  
Пример:
```c
int canDrive = 1; //true
```


## Присвояване на стойност

``<променлива> = <стойност>;``\
``<променлива> = <израз>;``\
``<променлива> = <друга променлива>;``

Пример:
```c
int sideA = 15;
int sideB = 20; // описваме правоъгълник

sideB = 25; // вече е по-широк правоъгълник

sideB = 25 * 2; // и още...

sideA = sideB; // вече е квадрат
```

## Преобразуване
Понякога се налага да работим с няколко вида числени типове. Важно е да знаем как да го правим коректно.

Когато се присвои дробно число към целочислен тип, то се закръгля надолу (или с други думи цифрите след запетаята изчезват). Този процес е необратим, и данните са перманентно изгубени.

В следния пример виждаме *неявно* (или имплицитно) преобразуване, защото се случва без наша намеса.
```c
int piInt = 3.141592; // piInt = 3
double pieDouble = piInt;   // pieDouble = 3
```

В следния пример виждаме *явно* (или експлицитно) преобразуване и се постига като сложим преди променливата типът, към който искаме да преобразуваме, в скоби.
```c
double pi = 3.141592;

int calculation = (int)pi * 100; // 300
```
Алтернативно:
```c
int calculation = int(pi) * 100; // 300
```
Важно е да знаем и да контролираме кога се случват преобразуванията, защото може да доведат до проблеми ако не се следят.
```c
int calculation1 = (int)pi * 100; // 300
int calculation2 = pi * 100;      // 314
```

## Изрази и операции
Езикът ни предоставя набор от операции, с които можем да създаваме изрази. Изразът може да се състои от една част, но по-често е множество от променливи с приложени *оператори*

Операторите в С++ са:
- аритметични: `+`, `-`, `*`, `/`, `%`
- логически: `&&`, `||`
- сравнителни: `==`, `!=`, `>`, `>=`, `<`, `<=`
- побитови: `&`, `|`, `^`, `~`, `<<`, `>>`
- унарни: `-`, `!`, `++`, `--`

```c
int calc = (1 + 2 / 3.2) % 10;
int canDrive = !hasDrunk && isOver18;
char theLetterB = 'A' + 1;
```

Операторите в C++ имат **приоритет**! Примерно когато напишем `int num = 1 + 2 * 3` ще се пресметне като `1 + (2 * 3)`, а не като `(1 + 2) * 3`, защото `*` има по голям приоритет от `+`. Ако някъде се чудите коя операция ще се изпълни първо, най-добре ползвайте скоби!

## ASCII таблица
Понеже компютърът може да работи само с числа, трябва да намерим някакъв начин да репрезентираме останалите символи, които могат да се появят на екрана като текст (букви, препинателни знаци и др.). най-простият начин е на всеки (по-популярен) символ да съпоставим едно число. Първата такава реализация е [ASCII таблицата](https://upload.wikimedia.org/wikipedia/commons/1/1b/ASCII-Table-wide.svg?utm_source=commons.wikimedia.org&utm_campaign=index&utm_content=original), Която използва 7 бита за да представи най-често използваните символи в компютъра. В последствие е разширена до 8 бита (1 byte), колкото е и типът `char`, който работи спрямо нея.


## Стандартната библиотека
Библиотека (в контекста на програмирането) най-просто казано е код, който някой друг е написал и ние може да ползваме на готово. За да го ползваме обаче, трябва да "добавим" библиотеката към нашия файл. На езика C, това става с `#include <...>`, където ... е името на библиотеката. За да принтираме информация на екрана и да приемаме такава от клавиатурата, ще използваме част от стандартната библиотека на езика C `stdio.h`. В началото на нашия код (извън мейн) пишем `#include <stdio.h>` за да ползваме споменатите функции по долу.


## Принтиране на конзолата
За да принтираме променлива на конзолата използваме функцията `printf("<текст за принтиране>")`. Какво е функция ще говорим малко по-късно, за сега само запомнете синтаксиса. Ако искаме обаче да принтираме стойност на променлива, за да я "вмъкнем" между текста в кавичките ще трябва да използваме т. нар. *форматиращ спецификатор* (format specifier). Всеки тип си има различен такъв:

таблица

Пример:
```c
int var1 = 67;
unsigned num1 = 4;
unsigned num2 = 5;

printf("var1"); //output: var1
printf("var1 = %d", var1); //output: var1 = 67
printf("%u + %u = %u", num1, num2, num1 + num2); //output: 4 + 5 = 9
```

За да отидем на нов ред докато принтираме (вместо да излиза всичко на един ред) може да добавим специалния символ `'\n'` на края на низ.

```c
printf("I'm on the first line. \nI'm on the second!");
```

## Четене от конзолата
Основна част от почти всяка програма е да може да получава входни данни от нейния потребител. За да прочетем стойност, въведена на конзолата на нашата програма, трябва да използваме функцията `scanf("<форматиращ спецификатор>", &<променлива>)`. Трябва да сложим правилния форматиращ спецификатор, който съответства на типа на променливата, където ще запазим прочетените данни. Пред името на променливата слагаме `&`, защо ще си говорим след няколко седмици :)

Пример:
```c
int num1;
int num2;

scanf("%d %d", &num1, &num2);
printf("The sum is %d", num1 + num2);
```
